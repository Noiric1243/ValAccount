# ValAccount By Noiric

一个轻量的 Windows Riot 账号启动器。选择本机保存的账号，在官方客户端登录页填入用户名和密码，再由用户完成人机验证和登录。

采用浅色圆角界面与红色强调色。支持多个账号、搜索、编辑和邮箱网页入口。

## 当前存档版本

便携单文件版 0.16。此项目以恢复的 v0.10 原始源码为基础，补回后续交付版的同目录存档、旧存档迁移和内嵌 V 图标。不是反编译项目；重新构建的二进制不保证与此前交付文件逐字节一致。

## 使用

双击 `VALO.exe`，添加账号后选择“启动并填入”。备注选填，留空时显示 Riot 登录名。邮箱地址、邮箱密码和邮箱登录网址均选填；网址可直接填写域名，常见邮箱会自动匹配网址。

点击邮箱链接会用默认浏览器打开邮箱登录页。游戏填入完成后程序退出。编辑、删除在主界面，“更多”包含账号资料和客户端位置。

程序优先读取已保存的客户端位置，其次读取本机 Riot 安装清单；找不到有效路径时才要求手动选择。已打开的可信客户端窗口可复用。程序不会自动退出当前已登录账号。

## 构建

要求 Windows 10/11 x64、.NET Framework 4.8 和 PowerShell。使用 Windows 的 .NET Framework C# 编译器；无需安装 NuGet 包或额外 SDK。

在项目目录运行：

```powershell
.\build.ps1
```

输出为 `bin\VALO.exe`，图标和应用清单已嵌入。不需要附带 `.config`、DLL 或图标文件，运行依赖系统安装的 .NET Framework。

如需重建图标：

```powershell
.\scripts\Generate-Icon.ps1
.\build.ps1
```

## 存档位置

首次保存时自动创建 EXE 同目录的 `data` 文件夹：

```text
VALO.exe
data/
  accounts.vault
  accounts.vault.bak
  diagnostics/
    fill-status.log
```

移动时同时移动 EXE 和 data。账号库通过 Windows DPAPI CurrentUser 加密，绑定当前 Windows 用户，不是跨电脑可解密的保险箱。同一用户权限下的恶意程序仍可能接触解密后的数据。

同目录已有账号库时优先使用。不存在时，尝试迁移旧版 `%LOCALAPPDATA%\ValoAccountManager\accounts.vault`，其次尝试 EXE 同目录 `ValoAccountManager\data\accounts.vault`。迁移保留原文件。

删除账号只更新当前账号库；上一版加密备份可能仍包含删除的条目。发给朋友时仅发 EXE，让对方自行录入账号。

## 网络与输入边界

管理器没有直接网络请求、账号上传、遥测和更新检查。用户点击链接时打开浏览器，启动游戏时打开 Riot 客户端，这些外部程序会自行联网。

填入使用 Windows UI Automation 定位控件及 SendInput 输入，并检查前台窗口与焦点。不读取认证 lockfile、会话令牌或游戏内存，不调用 Riot 非公开 API，不注入进程。不会提交登录或处理验证码。

这是非官方工具，没有 Riot 官方认证。客户端更新、界面语言、可访问性支持和权限差异可能导致识别失败；当前仍未完成真实 Riot 登录页端到端验收，不能把本地自测通过视为真实登录兼容性保证。

## 语言

打开后直接进入主界面，未设置时默认简体中文。可通过主界面“删除”和“更多”之间的独立按钮切换语言；中文界面按钮为 Language，英文界面为“语言”，设置保存在 EXE 同目录 data/language.txt，后续启动自动沿用。账号备注等用户数据不随界面语言翻译。添加账号页提示“没有的可以不填写”，登录名和密码仍为必填。

## 账号资料

更多 → 账号资料中显示游戏登录名、游戏密码、邮箱地址和邮箱密码，均支持分别复制。密码默认隐藏，可通过显示密码切换。未填写的邮箱项目显示占位提示并禁用复制。
